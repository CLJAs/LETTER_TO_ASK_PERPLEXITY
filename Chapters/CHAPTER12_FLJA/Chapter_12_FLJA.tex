	\newpage
	\noindent
	A relation is a set of pairs. So we can define how to build the relation, explaining how to create ALL pairs that are going to end inside the relation.
	\\\\
	
	\noindent
	For each SNEI, it is like Flja\_abstract ( SNEI ) =... but instead a fórmula, what you do algorithmically, is create one R-pair per each lcf in that previous table, and add all them INSIDE the set that defines the relation:\\\\
	FLJA\_ABSTRACT(SNEI) $\dashrightarrow$ PRODUCES  $\dashrightarrow$\\
	\{\\
		\indent ("That SNEI", $(\{\lambda_{1}\}DR1,\:\{\lambda_{1}\}DR0)$), \\
		\indent ("That SNEI", $(\{\lambda_{1}, \lambda_{2}, \lambda_{3}, \lambda_{4}, \lambda_{5}\}DR1,\:\{\lambda_{1}, \lambda_{2}\}DR0)$),\\
		\indent ... and so on, per each lcf that belongs to $LCF_{2p}$ inside that table ...\\	
	\}	
	\\\\
	
	\noindent
	You put ALL THOSE R-PAIRS, inside the relation (inside the set) Flja\_Abstract. Repeat it for each possible SNEI... NOW you have the complete relation well defined: we have explained how to create ALL the R-pairs of the relation. No more, no less.
	\\\\
	
	\noindent
	Each table is the Image set ( defined in the second chapter of this document ) of each SNEI. The table is ALL its images, ordered by universes.
	\\\\
	
	\noindent
	All R-pairs created are different:\\
	1) The table fits the construction ( SI(SNEI) X SI(SNEI) ), but with each element adapted to be a legal element of $LCF_{2p}$. All possible combinations, ALL different. An infinite quantity per each SNEI.\\
	2) In the right we could "repeat" some lcfs, but in the left of the R-pair, we are going to have different SNEIs when that happens.
	\\\\
	
	\noindent
	We need to see:\\
	1) All columns are infinite, but I need to put "..." to add more columns, below previous ones, to fit the table to the page.\\
	2) We have ordered lcfs by universes... in each column we have only elements coming from the same universe.\\
	3) In one column, we don't have THE ENTIRE universe. We only have all lcfs, related to THAT SNEI, in THAT UNIVERSE, in the Flja\_Abstract relation.\\
	4) Each SNEI have got related, lcfs from ALL universes... $\aleph_{0}$ from each universe, in $\aleph_{0}$ different universes. It could seem $\aleph_{0}^{2}$ different lcfs: $\aleph_{0}$ x $\aleph_{0}$. But we all now it is the same than only $\aleph_{0}$. 
	\\\\
	
	\noindent
	All clear now? Let's write some examples of different tables for a few concrete SNEIs. We will use them as examples in the future, too.
	\\\\
	
	\noindent
	\textit{FORGET that "r" in each "$r_{\theta_{k}}$" column tittle... just focus in the name of each universe $\theta_{k}$. We will talk about that "r" later.}
