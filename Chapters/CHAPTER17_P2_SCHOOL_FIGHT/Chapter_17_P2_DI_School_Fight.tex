	\section{Basic DI Resume}
	
	\noindent
	We begin with a candidate relation, in our case it will be FLJA\_abstract.\\\\
	We start to check all possible D-pairs in the cartessian product ( Domain X Domain ), in our case:\\(SNEIs X SNEIs).\\\\
	D-pair by D-pair, we will see if their PACKs (candidates to PACK) have elements in common, if that is the case, we erradicate that element from the entire relation.\\\\
	THAT means quitting from the original relation all R-pairs that contains those repeated elements.\\
	\\\\
	
	\noindent
	The final conditions are:\\\\
	1) If we have finished testing all possible combinations of D-pairs, and still each PACK has a cardinal bigger than ZERO: all are disjoint between them because we quitted all repeated elements between them. In this case, we created the conditions to apply the NAIVE CA Theorem. We can say Domain set has NOT a quantity of elements BIGGER than the quantity of elements inside Image set.\\\\
	2) If in any moment, some snei, only one, ends with its candidate PACK empty: we failed to apply Naive CA Th. We can not say something with value.
